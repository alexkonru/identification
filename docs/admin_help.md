# Справка по системе биометрической идентификации

## 1. Общие сведения

Система биометрической идентификации предназначена для контроля доступа в помещения на основе распознавания лица и голоса. Система состоит из серверной части (микросервисы на Rust) и клиентского приложения (Python, PyQt6).

## 2. Структура клиентского приложения

Клиентское приложение содержит следующие вкладки:

### 2.1. Мониторинг

Вкладка предназначена для просмотра видеопотока с камер и мониторинга событий системы.

**Элементы интерфейса:**

- **Дерево инфраструктуры** (левая панель) — отображает зоны, помещения и устройства в иерархическом виде.
- **Область видеопотока** (центральная панель) — отображает видеопоток с выбранной камеры.
- **Краткий лог системы** (правая панель) — отображает события присутствия, этапы идентификации и результаты принятия решений.
- **Системный лог** (правая панель, опционально) — отображает детальные сообщения от точек прохода.

**Порядок работы:**

1. Выберите камеру в дереве инфраструктуры.
2. Видеопоток отобразится в центральной области.
3. События мониторинга отобразятся в кратком логе.
4. Для отображения системного лога нажмите кнопку «Краткий лог системы».

### 2.2. Система

Вкладка отображает текущее состояние всех сервисов системы.

**Элементы интерфейса:**

- **Статус сервисов** — таблица с состоянием шлюза, базы данных, модуля распознавания лица и модуля распознавания голоса.
- **Сообщения системы** — журнал сообщений о функционировании системы.
- **Runtime настройки** — информация о текущем режиме выполнения (CPU/GPU), количестве потоков и состоянии модулей.

**Индикация состояния:**

| Индикатор | Значение |
|-----------|----------|
| Зелёный | Сервис доступен и работает |
| Красный | Сервис недоступен или произошла ошибка |

### 2.3. Настройки

Вкладка предназначена для управления системой и настройки интерфейса.

**Управление системой:**

- **Запустить систему** — активация конвейера обработки и идентификации.
- **Остановить систему** — деактивация конвейера обработки.

**Настройки интерфейса:**

- **Тема** — светлая или тёмная тема оформления.
- **Размер шрифта** — размер текста интерфейса (от 11 до 18 пунктов).
- **Голос в мониторинге** — включение или отключение голосовой модальности.
- **Системный лог по умолчанию** — отображение системного лога при запуске.

### 2.4. Персонал и доступ

Вкладка предназначена для управления пользователями и их правами доступа.

**Элементы интерфейса:**

- **Список пользователей** (левая панель) — перечень зарегистрированных пользователей.
- **Права доступа** (правая панель) — дерево зон и помещений с флажками для назначения прав.

**Порядок регистрации пользователя:**

1. Нажмите кнопку «Добавить».
2. Введите ФИО сотрудника в формате «Фамилия Имя Отчество».
3. Сделайте серию фотографий лица (5 снимков под разными ракурсами).
4. Запишите голосовые образцы (3 записи).
5. Нажмите «Сохранить пользователя».

**Порядок назначения прав доступа:**

1. Выберите пользователя из списка.
2. Отметьте помещения, в которые пользователь имеет доступ.
3. Нажмите «Сохранить права».

**Порядок удаления пользователя:**

1. Выберите пользователя из списка.
2. Нажмите кнопку «Удалить».
3. Подтвердите удаление в диалоговом окне.

### 2.5. Инфраструктура

Вкладка предназначена для управления зонами, помещениями и устройствами.

**Элементы интерфейса:**

- **Дерево инфраструктуры** (левая панель) — иерархическое представление зон, помещений и устройств.
- **Детали** (правая панель) — информация о выбранном элементе и управление замком.

**Порядок добавления зоны:**

1. Нажмите кнопку «+ Зона».
2. Введите название зоны.
3. Нажмите «Добавить».

**Порядок добавления помещения:**

1. Нажмите кнопку «+ Комната».
2. Введите название помещения.
3. Выберите зону из списка.
4. Нажмите «Добавить».

**Порядок добавления устройства:**

1. Нажмите кнопку «+ Устройство».
2. Введите название устройства.
3. Выберите помещение.
4. Выберите тип устройства (камера, микрофон, замок).
5. При необходимости нажмите «Обновить найденные источники» для автоматического обнаружения.
6. Нажмите «Добавить».

**Управление замком:**

1. Выберите устройство типа «замок» в дереве инфраструктуры.
2. В панели «Детали» нажмите «Открыть».

### 2.6. Журнал

Вкладка отображает историю всех попыток доступа.

**Столбцы таблицы:**

| Столбец | Описание |
|---------|----------|
| ID | Уникальный идентификатор записи |
| Время | Дата и время события |
| Пользователь | ФИО пользователя |
| Помещение | Название помещения |
| Доступ | Результат (разрешён или запрещён) |
| Детали | Подробная информация о событии |

### 2.7. Справка

Вкладка содержит справочную информацию и руководство пользователя.

## 3. Сообщения об ошибках

| Сообщение | Причина | Действие |
|-----------|---------|----------|
| «Сервис недоступен» | Серверный сервис не запущен | Запустите сервисы: `./start_docker.sh` |
| «Лицо не обнаружено» | В кадре нет лица | Подойдите ближе к камере |
| «Проверка живости не пройдена» | Обнаружена фотография или маска | Предъявите живое лицо |
| «Лицо не совпало» | Лицо не найдено в базе | Зарегистрируйте пользователя |
| «Нет прав доступа» | Пользователь не имеет прав в данное помещение | Назначьте права во вкладке «Персонал и доступ» |
| «Низкая уверенность» | Система не уверена в результате | Повторите попытку, улучшите освещение |

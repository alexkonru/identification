# Руководство пользователя системы биометрической идентификации

## 1. Назначение системы

Система биометрической идентификации предназначена для автоматического контроля доступа в помещения на основе распознавания лица и голоса. Система обеспечивает:

- Регистрацию пользователей с сохранением биометрических образцов.
- Назначение прав доступа к помещениям.
- Автоматическую идентификацию при прохождении через точку доступа.
- Ведение журнала событий доступа.
- Мониторинг состояния системы в реальном времени.

## 2. Запуск системы

### 2.1. Запуск серверных сервисов

1. Откройте терминал в директории проекта.
2. Выполните команду:

```
./start_docker.sh
```

3. Дождитесь запуска всех контейнеров.

### 2.2. Запуск клиентского приложения

1. Выполните команду:

```
python3 client/admin.py
```

2. Если сервер недоступен, в строке состояния отобразится соответствующее сообщение. Приложение продолжит работу, но функции идентификации будут недоступны до запуска сервера.

## 3. Настройка инфраструктуры

Перед началом работы необходимо настроить инфраструктуру: зоны, помещения и устройства.

### 3.1. Создание зон

1. Перейдите на вкладку «Инфраструктура».
2. Нажмите кнопку «+ Зона».
3. Введите название зоны (например, «Корпус А»).
4. Нажмите «Добавить».

### 3.2. Создание помещений

1. На вкладке «Инфраструктура» нажмите кнопку «+ Комната».
2. Введите название помещения (например, «Лаборатория 101»).
3. Выберите зону, к которой относится помещение.
4. Нажмите «Добавить».

### 3.3. Добавление устройств

1. На вкладке «Инфраструктура» нажмите кнопку «+ Устройство».
2. Заполните поля:
   - **Название** — произвольное имя устройства.
   - **Комната** — помещение, в котором установлено устройство.
   - **Тип** — камера, микрофон или замок.
3. Для камер и микрофонов нажмите «Обновить найденные источники» для автоматического обнаружения подключённых устройств.
4. Нажмите «Добавить».

**Требования к конфигурации точки прохода:**

| Устройство | Количество | Обязательно |
|------------|------------|-------------|
| Камера | 1 | Да |
| Замок | 1 | Да |
| Микрофон | 0 или 1 | Нет |

## 4. Регистрация пользователя

1. Перейдите на вкладку «Персонал и доступ».
2. Нажмите кнопку «Добавить».
3. В открывшемся окне введите ФИО сотрудника в формате «Фамилия Имя Отчество».
4. Убедитесь, что видеопоток с камеры отображается.
5. Нажмите «Сделать снимок» и сделайте 5 фотографий лица под разными ракурсами. Система автоматически оценивает качество каждого снимка.
6. Нажмите «Записать голос» и произнесите фразу: «Я подтверждаю свою личность и право доступа в помещение». Выполните 3 записи.
7. После сбора всех образцов кнопка «Сохранить пользователя» станет активной.
8. Нажмите «Сохранить пользователя».

**Требования к качеству снимков:**

- Лицо должно быть обнаружено и занимать достаточную площадь кадра.
- Освещение должно быть достаточным (не слишком темно и не слишком ярко).
- Кадр не должен быть смазан.
- Рекомендуется снимать лицо под разными углами.

**Требования к голосовым образцам:**

- Голос должен быть обнаружен в записи.
- Запись должна содержать речь, а не фоновый шум.
- Произносите фразу обычным голосом, без повышения тона.

## 5. Назначение прав доступа

1. На вкладке «Персонал и доступ» выберите пользователя из списка.
2. В правой панели отобразится дерево зон и помещений.
3. Отметьте флажками помещения, в которые пользователь имеет доступ.
4. Нажмите «Сохранить права».

**Рекомендация:** не назначайте пользователю доступ более чем к 7 помещениям (принцип 7 плюс-минус 2).

## 6. Запуск системы идентификации

1. Перейдите на вкладку «Настройки».
2. В группе «Система» нажмите кнопку «Запустить систему».
3. Убедитесь, что индикатор состояния изменился на «Работает».
4. Перейдите на вкладку «Система» и проверьте, что все сервисы отображаются как «Онлайн».

## 7. Мониторинг

1. Перейдите на вкладку «Мониторинг».
2. В дереве инфраструктуры выберите камеру.
3. Видеопоток отобразится в центральной области.
4. В правой панели отображается краткий лог с событиями:
   - Обнаружение присутствия.
   - Этапы идентификации.
   - Результат принятия решения.
5. Для отображения детального системного лога нажмите кнопку «Краткий лог системы».

**Расшифровка записей лога:**

| Запись | Значение |
|--------|----------|
| ДОСТУП | Доступ разрешён |
| ОТКАЗ | Доступ запрещён |
| обнаружено лицо | Лицо обнаружено в кадре |
| живость: OK | Проверка живости пройдена |
| идентификация лица: OK | Лицо совпало с записью в базе |
| идентификация голоса: OK | Голос совпал с записью в базе |
| доступ в помещение: OK | Пользователь имеет право доступа |

## 8. Просмотр журнала доступа

1. Перейдите на вкладку «Журнал».
2. Нажмите «Обновить журнал» для загрузки последних записей.
3. Таблица содержит:
   - Идентификатор записи.
   - Дату и время события.
   - ФИО пользователя.
   - Название помещения.
   - Результат (разрешён или запрещён).
   - Детали события.

## 9. Остановка системы

### 9.1. Остановка конвейера обработки

1. Перейдите на вкладку «Настройки».
2. Нажмите кнопку «Остановить систему».
3. Обработка кадров и идентификация будут приостановлены.

### 9.2. Остановка серверных сервисов

1. Откройте терминал в директории проекта.
2. Выполните команду:

```
./stop_docker.sh
```

## 10. Настройка интерфейса

1. Перейдите на вкладку «Настройки».
2. В группе «Интерфейс» настройте параметры:
   - **Тема** — светлая или тёмная.
   - **Размер шрифта** — от 11 до 18 пунктов.
   - **Голос в мониторинге** — включение голосовой модальности.
   - **Системный лог по умолчанию** — отображение системного лога при запуске.
3. Нажмите «Сохранить параметры интерфейса».

## 11. Диагностика и устранение неисправностей

| Проблема | Возможная причина | Решение |
|----------|-------------------|---------|
| Сервис недоступен | Серверные сервисы не запущены | Выполните `./start_docker.sh` |
| Камера не отображается | Устройство не добавлено в инфраструктуру | Добавьте камеру на вкладке «Инфраструктура» |
| Лицо не обнаруживается | Недостаточное освещение или расстояние | Улучшите освещение, подойдите ближе |
| Голос не записывается | Микрофон не подключён или не выбран | Проверьте подключение микрофона, добавьте устройство |
| Доступ запрещён | Пользователь не имеет прав в помещение | Назначьте права на вкладке «Персонал и доступ» |
| Низкая уверенность | Плохое качество биометрических образцов | Перерегистрируйте пользователя с лучшими образцами |
